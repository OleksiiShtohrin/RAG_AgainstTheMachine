# RAG Against the Machine

## Description
**RAG Against the Machine** is a modular, high-performance Retrieval-Augmented Generation (RAG) system built to ingest, index, search, and answer complex technical inquiries regarding the `vLLM` codebase.

Rather than relying purely on static LLM parametric knowledge, this system dynamically indexes documentation and code using BM25Okapi lexical retrieval with subword identifier tokenization, pairs it with dense semantic embeddings, and generates accurate, grounded answers using a local compact language model (`Qwen`).
